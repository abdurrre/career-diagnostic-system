# main dataset
Dataset ini jadi sumber data utama yang berisi informasi kualifikasi untuk berbagai profesi di bidang teknologi. Isinya gabungan dari dataset Data Science Job Postings & Skills (2024) dan hasil web scraping lowongan kerja dari Jobstreet Indonesia.

Dataset ini dipakai khusus di notebook **Data_augmented_part_1.ipynb** untuk bikin baseline awal sistem.

**Kendalanya**, distribusi datanya **masih belum seimbang** karena data untuk role di rumpun Software Engineering jumlahnya jauh lebih sedikit dibanding role lainnya.
